# Employee Management SQL Task

## Overview
This project demonstrates SQL skills using MySQL to manage employee records and perform salary-related analysis through stored procedures.

## Features
- **Employee Salary Report:** Retrieves active employees based on department and minimum salary.
- **Salary Calculation:** Calculates net salary using basic salary, HRA, DA, and PF components.
- **Salary Grade:** Assigns salary grades based on salary ranges.
- **Department Summary:** Calculates employee count, average salary, highest salary, lowest salary, and total salary expenditure by department.

## Technologies Used
- MySQL
- SQL Stored Procedures
- Aggregate Functions
- CASE Expressions
- Common Table Expressions (CTEs)

## How to Run
1. Open MySQL Workbench or another MySQL client.
2. Execute the `SQL TASK.sql` script to create the database, employee table, sample records, and stored procedures.
3. Call the procedures with appropriate input parameters to view the results.

## Purpose
This task demonstrates practical knowledge of SQL queries, stored procedures, conditional logic, salary calculations, and aggregate functions.
